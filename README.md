# PortalSync pictures

Optional figure pictures for [PortalSync](https://github.com/rhsts/portalsync). In PortalSync, open **Add Skylander…** and click **Get pictures…**: it downloads `thumbnails.zip` from the latest release here and puts the pictures next to PortalSync. After that, Add Skylander has a **Table / Pictures** switch.

The release holds 591 pictures, one per figure in PortalSync's list, named `<figure ID>_<variant>.png` (for example `25_0.png` for Zook), at 96 × 96 pixels.

## Where the pictures come from

These are existing character illustrations, game images and figure photographs collected by Skylanders fans. They were only resized; nothing was drawn or generated. The sources and the match for every figure are in [ATTRIBUTION.md](ATTRIBUTION.md) and [manifest.json](manifest.json).

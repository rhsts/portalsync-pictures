# Skylanders thumbnail artwork

These are existing character illustrations, game images and figure photographs, not generated artwork.
They have been resized proportionally and placed on transparent 96 x 96 PNG canvases for this preview.
The original image content and any existing watermarks are retained.

Sources:

- [Portal Master Collection Vault](https://github.com/PinkLemonade45/Portal-Master-Collection-Vault),
  commit `5daa5be244a938049bf5752cadfada6e0f4cb0f3`, `assets/images/portraits`.
  Its catalog provides figure and variant IDs used for matching. The source repository's
  Apache-2.0 license is included as `PORTAL-MASTER-LICENSE.txt`.
- [Skylanders Collector](https://github.com/Karasu-huginn/Skylanders_Collector),
  commit `67725e9579368233f639681cad58a4bdeaac74b3`, `react/public/assets`.
  That catalog's scraper identifies [Skylanders Character List](https://skylanderscharacterlist.com/)
  as its image source.

Skylanders characters, names and original artwork belong to Activision and their respective owners.
Third-party artwork is separate from PortalSync's GPL-licensed program code; no new ownership or
license over the original artwork is asserted here. This is an unofficial fan project.

`manifest.json` records a source URL, source label and match type for each figure ID/variant.
572 entries are mapped to matching artwork; 10 Swapper halves show a whole-figure image;
9 special/instant variants use the same character's standard image. The last two cases are labeled
on the thumbnail cards. The latter are:

- Platinum Hidden Treasure
- Gear Head Vicarious Visions Wind Up
- Instant Hot Streak, Stealth Stinger, Dive Bomber, Spitfire, Super Shot Stealth Elf and Dive-Clops
- Patina Lava Lance Eruptor

No save files, game files, music or sounds from the source projects are included.
